How to join

  1. Open Minecraft Java Edition and select Multiplayer.
  2. Select Add Server.
  3. Paste the server address above and select Done.
  4. Select the server and join.

Server rules

  • Be kind. No harassment or hate speech.
  • Griefing is allowed. Protect your base or accept the risk.
  • No cheating, x-ray or unfair mods.
  • Keep chat friendly and free of spam.
  • Listen to staff. Their decisions are final.
